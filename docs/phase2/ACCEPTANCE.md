# Phase 2 acceptance matrix

Status: **Phase 2 acceptance under the production-read-only OpenClaw boundary.** OpenClaw owns its runtime and catalog lifecycle. ANTIGRAVITY qualification may observe the already-running production host through supported public contracts, but must not install, downgrade, upgrade, restart, stop, reconfigure, patch or replace OpenClaw, its Gateway, configuration or package selection. This is the single acceptance matrix consumed by t002–t006 (source fixtures), t007 (frozen integrated qualification), and t008 (independent acceptance). [Architecture](../ARCHITECTURE.md) defines the normative contracts. All rows below are required for their applicable claimed capability; a conditional image/platform case is explicitly exercised as supported or rejected, never silently omitted.

## 1. Evidence and identity rules

A source/design PASS is not installed-host, AGY, OS or release qualification. For every executed row record the exact source/export/tarball, observed host/Node/AGY identities, scenario, observed assertions, result and minimal non-sensitive evidence reference. Use the existing task-owned campaign result, not a new record for every assertion. Classify each row as authored, executed-pass, executed-fail, blocked, or not-executed. Record exclusions and their approved support/requirement decision. A row is not passed merely because a script exists, an API name exists, a timeout promise returned, or a fixture restates implementation flags.

Freeze one integrated candidate before t007. Qualification tests the packaged bytes, not only TypeScript source. Any payload rebuild invalidates evidence for the changed identity; affected requalification plus integration sanity is mandatory. t008 independently verifies decisive behavior using the same bounded harness against the same qualified package. Worker-run evidence is not renamed independent QA. Publication and merge remain separate authority after acceptance; p02 uses no universal third ratification.

### Execution campaign and dependency joins

The prepared [build/export recipe](../BUILD.md) and [qualification runner](../QUALIFICATION.md) provide the executable source and host campaign path. Runner unit results reference these existing row IDs; they are not a second acceptance matrix. A passing source/offline unit leaves current-production-host and live AGY observations in this matrix unverified until t007 supplies them and t008 independently accepts them.

The campaign establishes actual hostname, exact host governance, isolated ANTIGRAVITY-owned workspace/configuration, permitted authentication, finite time/spend bounds and retention **before any ANTIGRAVITY/AGY host operation**. Production OpenClaw is read-only context and is not a campaign installation or lifecycle target. Use offline fixtures before paid/native AGY actions and stop dependent units after a required failure. Necessary corrections freeze new identities and rerun impacted rows; they do not add a review per checkpoint. Transient ANTIGRAVITY execution material is removed after final use rather than accumulated on the production host.

t002–t006 can develop against C01–C05 after design acceptance, with t004 owning host public-contract mapping and t005 consuming its provider/catalog hooks. A source candidate may be reviewed with explicitly unexecuted host scenarios; it cannot advertise those scenarios as passing or complete the Phase 2 release before t007/t008. t007 owns the execution results and t008 independently checks their decisive claims. Required infeasible capabilities go to the existing task's decision boundary; optional deferred features do not become acceptance blockers.

## 4. Executed credential-free design checks

Command from repository root: `python docs/phase2/check_contract.py` (Python standard library only, no network, native binaries or credentials). The checker validates matrix/probe/interface cross-references, fixed task dependencies, the production-read-only OpenClaw boundary, provider-hook/host-owned lifecycle declaration, the combined cleanup budget, a conservative replay truth table, the one-user-message encoding contract and limit shape. It also checks that design-owned paths and explicit unqualified status remain present. These are finite design consistency checks, **not AGY/SDK integration tests**.

The current check covers 24 matrix rows, six named probes, five shared contracts, 18 replay cases (one safe case), five single-frame encoding round trips and nine phase dependencies. Native AGY, packed current-host compatibility and founder live acceptance remain separate qualification evidence; the design checker performs no OpenClaw lifecycle operation and creates no production-host mutation.
